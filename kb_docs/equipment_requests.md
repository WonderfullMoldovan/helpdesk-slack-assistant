# Hardware Equipment Requests

## Standard Equipment

All employees are eligible for standard equipment:

- **Laptop**: ThinkPad T-series (Windows) or MacBook Pro 14" (Mac)
- **Monitor**: 27" Dell U2723QE (4K)
- **Keyboard**: Logitech MX Keys
- **Mouse**: Logitech MX Master 3S
- **Headset**: Jabra Evolve2 65
- **Webcam**: Logitech Brio (for non-laptop setups)

## How to Request

### New Employees

Standard equipment is automatically ordered by HR upon hire. Expected delivery is 5 business days before start date.

### Existing Employees - Refresh

Standard refresh cycle is every 3 years for laptops, 5 years for monitors and peripherals.

To request refresh:
1. Open ticket via https://itportal.company.com
2. Select "Equipment Refresh"
3. Provide:
   - Current device serial number
   - Reason for refresh (age, malfunction, role change)
   - Manager approval (auto-routed)

Approved refreshes ship within 7 business days.

### Existing Employees - Additional Equipment

For equipment beyond standard (e.g., second monitor, standing desk, ergonomic chair):

1. Manager pre-approval required
2. Open ticket with manager in CC
3. Specify business justification
4. IT will review against role requirements

Common approvals:
- Second monitor: All engineering roles, designers, financial analysts
- Standing desk: Available with medical documentation
- Premium headset: Customer-facing roles, frequent meeting participants

## Equipment Return

When leaving the company or upgrading:

1. Receive return shipping kit from IT (auto-sent)
2. Pack equipment in original boxes if available
3. Include all accessories (chargers, cables)
4. Drop at any FedEx location with prepaid label
5. Email IT with tracking number

## Damaged or Lost Equipment

Report immediately via Slack #it-support:

- **Damaged**: Provide photos, describe incident
- **Lost or stolen**: File police report first if stolen, then notify IT
- **Replacement cost**: Insurance covers normal wear; intentional damage or negligence may incur cost

Loss of equipment must be reported within 48 hours.

## Loaners

While awaiting refresh or repair, request loaner via:
1. Slack #it-support
2. Specify equipment type and duration
3. IT confirms availability
4. Pickup at IT office or shipped if remote

Loaners available for laptops, monitors, headsets.
